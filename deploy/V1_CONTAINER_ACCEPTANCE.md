## 本轮发现并修复

空 MySQL 卷初始化后，部分演示中文出现乱码。基础 SQL 使用 `SET NAMES utf8mb4`，但 Docker 对每份 SQL 单独打开连接，演示/升级脚本不能继承该会话设置。已在 `sql/citygo-demo.sql`、`sql/citygo-upgrade.sql` 开头显式声明 utf8mb4。

修正后使用全新数据库初始化，HTTP 精确核对商户名称/区域、分类、秒杀券标题；浏览器核对首页和中文搜索结果，均正确。此修复防止新导入乱码；不能自动修复已有库中已经错误解码、且演示 SQL 不更新的历史数据。已有部署应先核对数据，再决定是否修复，不重新导入含 DROP TABLE 的基础 SQL。
